# Aptelecom Retail Management System

نظام إدارة فروع التجزئة لشركة Aptelecom

## المميزات
- تسجيل دخول متعدد الصلاحيات
- لوحة تحكم مع رسوم بيانية
- تتبع الحضور والانصراف
- قائمة تفتيش شاملة (3 أقسام)
- إدارة الفروع والمديرين
- تصدير Excel و PDF
